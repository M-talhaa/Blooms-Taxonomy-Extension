## 6. Pairing of 'rest' and 'copy' in the original submission

- 'rest': the votes are recorded for 'rest' (workbook column Verb_clean), but the v1 table paired them with the model output for 'resting' (column Verb) (normalization audit: resting -> rest, lemmatized). Stored v1 output: primary Cm, hard ['Cm']. The archived model on 'rest': primary Ap, hard ['Ap'] (strict 1, endorsed 1).
- 'copy': the votes are recorded for 'copy' (workbook column Verb_clean), but the v1 table paired them with the model output for 'copying' (column Verb) (normalization audit: copying -> copy, dropped-core-leak). Stored v1 output: primary Kn, hard ['Kn']. 'copy' is a core training verb (in the 358-verb core: True; in the 381-verb core: True), so it is not a candidate and counts as a miss for every model on D30.
- Effect: v1 as reported 6/30 strict and 14/30 endorsed. Scoring the rated form 'rest' with the same model changes these by +1 and +1 (7/30, 15/30). On normalized forms with 'copy' counted as a miss, OLD scores 7/30 and 14/30 (Section 2). The v1 sample therefore contained one core-verb variant ('copying').
